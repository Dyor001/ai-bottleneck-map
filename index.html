What it does / 做什么

It takes broad themes like CPO, HBM, cooling, power, or robotics and forces them down into constrained, hard-to-scale layers before ranking listed companies.

What it avoids / 避开什么

It does not confuse an interesting clue with an investable mapping. The skill keeps evidence, timing, and falsification explicit instead of hiding behind theme momentum.

What it outputs / 输出什么

Bottleneck maps, node cards, re-rating triggers, stage labels, and kill conditions that can feed a real industry-chain knowledge base.

Example prompt / 示例提示词

Use the skill when you want the chain logic before the ticker list. 需要先看产业链逻辑、再看公司时就用它。

Use ai-bottleneck-map to break down CPO into bottleneck layers first,
then rank the cleanest listed company mappings with evidence, timing,
re-rating triggers, analogs, and kill conditions.
